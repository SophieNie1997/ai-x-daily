# AI X Daily

Chinese daily digest site for public X/Twitter updates from important AI researchers, founders, and builders.

## Local Build

```bash
npm test
npm run build
```

The generated static site uses:

- `index.html`
- `daily/YYYY-MM-DD.html`
- `assets/site.css`
- `site-data/reports.json`

## Publishing

The repository is intended to publish with GitHub Pages through `.github/workflows/pages.yml`.
