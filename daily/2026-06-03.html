今天这批账号里，真正值得看的内容集中在 4 条线：AI 政策、AI 教育与研究、AI coding/agent 的真实生产率、开源模型与本地 agent 的上升。

1

@sama 表态支持美国最新 AI 行政令，核心主张是“领先 + 安全 + 防御落地”。

要点：Sam Altman 说，美国应该继续做最好的模型、确保安全，并把 cyber tools 交到可信防御者手里；他明确评价这份新 EO “balance right”。这代表 OpenAI 对当下美国 AI 政策方向的公开站队：不是单纯放松监管，而是把国家竞争力、安全和实战防御绑在一起。

链接：https://x.com/sama/status/2061973280655904815

2

@emollick 继续强调：AI 在高校和研究体系里的全面接入，正在从试验走向基础设施。

要点：他提到芝加哥大学接入 Claude 不值得意外，很多学校已经是校级 AI 接入；真正关键的是 safe and equitable access，以及 HIPAA、FERPA 合规。这个信号值得重视，因为它说明高校对 AI 的采用已不再是零散教师试用，而是在往制度化部署走。

链接：https://x.com/emollick/status/2061977762861092994

链接：https://x.com/emollick/status/2061978439595212831

链接：https://x.com/emollick/status/2061979197535322213

3

@emollick 对“everything app”式 AI 产品的批评很到位：现在很多产品仍然像“聊天机器人 + IDE”的混合体，不适合一般知识工作。

要点：他认为这类产品过度假设线性流程，太关注最终输出，缺少研究连接、用户中途 steering 和 selection。这个判断很重要，因为它点出了 agent 产品的一个真实瓶颈：不是模型不会做，而是交互范式还没长对。

链接：https://x.com/emollick/status/2061931631124914452

4

@emollick 对 Microsoft 新模型 MAI-Thinking-1 的评价偏保留，但认可技术文档。

要点：他认为仅看分数很难判断模型真实水平，而且微软让新模型难以上手试用，影响外界判断；不过他同时称赞技术 write-up 很扎实。这反映出一个行业争议：模型发布如果缺少足够开放的可用性，再好的 benchmark 也难形成真实口碑。

链接：https://x.com/emollick/status/2061907785768489127

链接：https://x.com/emollick/status/2061908259137523824

5

@emollick 引用法律教育研究，显示 Gemini 2.5 在特定问答任务里已显著压过人类教授。

要点：在盲评里，Gemini 胜率 75%，且回答被认为比人类更少 harmful。虽然这不代表全面替代，但它非常说明问题：在高结构化、高知识密度的解释型任务里，前沿模型已经能稳定进入“专家可用”区间。

链接：https://x.com/emollick/status/2061876620638486584

6

@emollick 转述 AI coding agents 论文，给出一个很值得盯的数据点：代码产出飙升，不等于上线结果同比例增长。

要点：论文里 autocomplete 工具让代码量到 2.2x，本地 agent 到 7.4x，远程 coding agents 到 17.3x；但实际发布只增长约 30%。这基本点明了当下 agent 的现实边界：写代码不再是主瓶颈，人类审查、取舍、集成才是。

链接：https://x.com/emollick/status/2061659432233161023

链接：https://x.com/emollick/status/2061815740542414949

7

@ClementDelangue 今天最值得看的观点，是“前端不该让用户手动选模型，而该自动路由”。

要点：他认为，如果 UI 在后台自动路由模型，而不是把 model picker 丢给用户，价值和调用量会重新分配给更多开源、小模型、便宜模型，而不再默认流向 frontier model。这是一个很关键的产品判断：模型层竞争，越来越会由默认路由而不是用户显式选择决定。

链接：https://x.com/ClementDelangue/status/2061871024627482964

行业趋势和争议：

  • AI 政策正在变成“国家竞争力 + 安全 + 防御能力”三位一体叙事，@sama 的发言很典型。
  • 高校和研究机构的 AI 采用进入制度化阶段，合规部署会越来越重要。
  • Coding agent 的核心矛盾越来越清楚：生成速度远超组织消化速度，人类 review/集成仍是瓶颈。
  • 产品层的一个关键分歧正在出现：是让用户自己选模型，还是让系统自动路由模型。
  • 开源、本地 agent、open-weight 模型的分发势头仍然很强，Hugging Face 阵营在持续加速这条线。
